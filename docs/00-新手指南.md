# Godfather 新手快速上手指南

本指南用直白的话介绍如何从零启动 Godfather、配好本地/远程教师模型、批量整理训练数据并微调你自己的本地小模型。

---

## 1. 先检查一遍你需要的东西

- **必须**：Python 3.10–3.12。
- **做 Markdown → LaTeX 任务包时需要**：
  - 安装 **XeLaTeX**（Windows 推荐 TeX Live 或 MiKTeX；若是 MiKTeX 首次编译缺失字体包，请打开 MiKTeX Console 并把「Install missing packages on-the-fly」设为 Always）。
  - Pandoc 属于**可选工具**：如果你只打算用内置规则 `rule_only` 或直接上大模型 `teacher_direct`，没有 Pandoc 照样全功能跑通。
- **使用远程大模型教师（可选，大幅省显存）**：支持 DeepSeek、MiniMax、阿里云百炼 / Qwen、Moonshot Kimi、智谱 GLM 或本地 vLLM/OneAPI，填入 API Key 即可。
- **要跑本地小模型微调时**：
  - 建议安装带 CUDA 支持的 PyTorch，并预留足够的本地磁盘存放 HuggingFace 基座权重；
  - 导出 GGUF 时，先下载/编译好 `llama.cpp`，在设置里指明目录即可（注意新版 `llama.cpp` 默认编译在 `build/bin/Release` 下，本框架已兼容常见可执行文件位置）。

---

## 2. 启动工作台

```bash
python -m godfather serve
```

打开浏览器访问 <http://127.0.0.1:8760>：

1. 点击顶部工具栏里的 **`＋ 新建项目`**（不再有旧文档说的“右上角＋”了，按钮就在顶栏中间项目下拉框旁边）。
2. 选择项目挂载的任务包：
   - **Markdown → LaTeX**：完整图文排版、四层质量告警、PDF 可视化框选与多源块协同修订；
   - **通用指令微调（General SFT）**：上传 JSONL / JSON / CSV / Markdown 对话或问答，做通用垂直领域小模型微调。

---

## 3. 配置教师与预算（可选使用远程 API）

打开左侧栏 **`模型接入中心`**：
- 点选顶部厂家快捷预设（如 DeepSeek、MiniMax、Qwen），填好你的 `API Key` 和 `默认模型`（如 `deepseek-chat`）。
- 点 **「探测模型列表」** 确认密钥鉴权无误，再点 **「发送测试对话 Ping」** 验证真实能回话。
- 如果填写了 Token 单价并勾选计费核算，别忘了在右侧「安全预算与硬上限闸门」勾上 **「允许已定价付费调用」** 并保存，所有生成和批注修订就能立刻切到远程强教师上跑了。
- 若使用本地 Ollama 跑教师或评测，训练前记得在 **`模型接入中心`** 或 **`训练与模型`** 页面点一下 **「一键释放显存」**，把常驻显存先还给 PyTorch 训练进程。

---

## 4. 标注工作台的正确用法（多选源块修订）

在 **`标注工作台`** 中：
- 拖框画在 PDF 某一片区域上会打开「新建批注」弹窗；如果嫌手画不准，可以直接点右栏的 **`＋ 手动新建批注`**，或者在左侧源块栏开启 **`开启左栏多选`** 勾中多个块再批量发起批注。
- 弹窗或卡片上的 **「指定源块 (多选)」** 按钮打开了全新的搜索勾选器：
  - 支持关键词搜索（按 `block_id`、标题、片段过滤）；
  - 支持按类型过滤（公式 / 表格 / 段落 / 代码）；
  - 按住 `Shift` 单击两头可范围连选；
  - 选完保存后，批注会直接标成 **已确认定位 (`confirmed`)**，不再因为模糊待审而在修订时静默错位或报错。
- 点击「**接受并修订**」弹窗中还可以自由临时指定使用本地 Ollama 还是远程 API 教师来改这一块。修订完成通过校验后，新版本会自动写回 `document_revisions` 并提示切换到新一轮预览。

---

## 5. 筛选样本、试算快照与本地训练

1. 打开 **`样本与快照`**：用顶部状态标签筛选 `candidate`（待审候选），勾中复选框一键 **批量接纳 (accepted)**。
2. 点击右上角 **「冻结新数据快照」**：可自行调 `train / dev / holdout` 比例或点选预设（例如小样本可设 `60/20/20`），系统会在**正式写盘前**先给出真实集群切分试算数字和告警，确认后再冻结一份带 SHA-256 指纹的只读 JSONL 快照。
3. 打开 **`训练与模型`**：选好快照与基座模型，确认 `max_seq_length`（推荐至少 `2048`）后点启动训练。脚本会在加载大模型权重前先行分词预检——若发现某条超长或配置过小导致零监督信号，会在几秒内清晰报错，不再空等加载完模型才崩溃。
